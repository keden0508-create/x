# Universal Cooking (Fabric, Minecraft 26.3)

요리 모드. 음식 12종 + 재료(소금, 후추) + 쌀 작물 + 레시피.

| 아이템 | 레시피 |
|---|---|
| 달걀프라이 | 달걀 → 화로 / 훈연기 / 모닥불 |
| 달걀 샌드위치 | 빵 / 달걀프라이 / 빵 (세로) |
| 햄버거 | 빵 / 익힌 소고기 / 빵 (세로) |
| 과일 샐러드 | 그릇 + 사과 + 달콤한 열매 + 수박 조각 |
| 꿀 토스트 | 빵 + 꿀병 |
| 생선 꼬치 | 막대기 + 익힌 대구 + 익힌 연어 |

## jar 받는 법
- push 하면 GitHub > Actions > 최근 실행 > Artifacts 에서 jar 다운로드
- `git tag v0.1.0 && git push --tags` 하면 Releases 탭에 jar 자동 등록

## 필요한 것
Minecraft 26.3 / Fabric Loader 0.19.3+ / Fabric API / Java 25
